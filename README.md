# Shreshtha OS

My portfolio as a tiny Linux desktop in the browser: boot screen, window manager, terminal, files, editor, htop, GitHub, resume and mail.

## Run it
Open `index.html` in a browser. Nothing to install yet.

## Edit
- GitHub username: search for `GH_USER` near the top of the main script.
- Content: the `CV` object near the top of the main script.
